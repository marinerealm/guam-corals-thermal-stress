# Outstanding before publication

- [ ] **AriaMx instrument export.** `data/raw/qpcr/qPCR_Cq_values.csv` holds the
      extracted Cq values, but not the run files or melt curves. The Methods
      state that melt-curve analysis was used in place of standard curves to
      confirm single products, so the melt curves are the evidence for that
      claim and should be deposited in `data/raw/qpcr/`.
- [ ] **Original `.hobo` logger files.** Only the CSV exports are present in
      `data/raw/logger/`. The `.hobo` files are the unmodified instrument
      output and belong beside them.
- [ ] **Fragment inventory.** Any record mapping nubbins to parent colonies,
      and anything written down during the 10 March session. The repository
      documents that tank assignment was reconstructed for 11–17 March; a
      contemporaneous record would strengthen that considerably.
- [ ] **Zenodo DOI.** Link the repository in Zenodo, cut a GitHub release, and
      put the resulting DOI in the manuscript's Data Summary and in
      `CITATION.cff`.
